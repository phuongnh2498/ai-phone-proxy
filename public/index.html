Connect your phone

Scan with the iPhone camera (same Wi-Fi). The setup page pairs the phone and walks you through:

  1. Wi-Fi ⓘ → Configure Proxy → Automatic → URL:
  2. Download certificate (Safari) → Settings → Profile Downloaded → Install
  3. General → About → Certificate Trust Settings → enable
  4. Check: open http://proxy.setup on the phone

Manual alternative: Configure Proxy → Manual →
Games / apps missing? Many game engines ignore the Automatic (PAC) setting. Use Manual instead.
Android: Wi-Fi → Modify → Proxy Manual, then install the cert from the setup page (Settings → Security → Install certificate → CA certificate). Android 7+ apps only trust it if they opt in.
